# Text-to-SQL

Ask in plain English, get production-ready SQL — a multi-step LLM pipeline over a structured semantic layer.

Text-to-SQL converts natural language questions into executable SQL queries using a LangGraph pipeline that decomposes the question, maps it to the right schema context, generates SQL, and validates the output. Built on the Olist Brazilian e-commerce dataset (9 relational tables), currently at v1.0 with v2.0 (semantic layer, agentic routing, FastAPI backend) in progress.
